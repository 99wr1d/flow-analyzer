# FlowAnalyzer

Футбольный видеоанализатор — настольное приложение (Electron + React + TypeScript).
Сейчас готовы: безопасное окно, тёмный интерфейс, импорт видео и плеер (пуск/пауза, скорость, перемотка, громкость, таймлайн) и установщик для Windows.
Дальше: покадровый переход, рисование поверх видео, метки на таймлайне, проекты, экспорт в MP4, трекинг игроков, клипы и статистика.

## Требования

- Windows 10/11
- Node.js 24
- npm

## Команды

```bash
npm install          # установить зависимости
npm run dev          # запустить приложение в режиме разработки
npm run lint         # проверка кода
npm run typecheck    # проверка типов
npm test             # юнит-тесты (vitest)
npm run test:e2e     # сборка + тесты приложения в Electron (Playwright)
npm run build:win    # установщик: dist/FlowAnalyzer-Setup-0.2.0.exe
```

## Видео

Открыть видео: кнопка «Открыть видео» (или `Ctrl+O`), либо перетащить файл на окно.

Поддерживаемые форматы: **MP4 (H.264)**, **WebM**, **MOV**; расширения `.mp4`, `.m4v`, `.mov`, `.webm`, `.mkv`.
Приложение воспроизводит видео встроенным движком Chromium, поэтому файл должен быть в формате, который он умеет
декодировать. Если файл не открывается (например, H.265/HEVC или экзотический кодек), приложение покажет понятное
сообщение. Другие форматы научимся открывать позже. `.mkv` принимается, но играет только если внутри H.264/VP8/VP9.

### Горячие клавиши

| Клавиша     | Действие                                          |
| ----------- | ------------------------------------------------- |
| `Ctrl+O`    | открыть видео                                     |
| `Пробел`    | пуск / пауза                                      |
| `[` и `]`   | скорость медленнее / быстрее (0.25×–2×)           |
| `M`         | выключить / включить звук                         |
| `Home/End`  | (на полосе перемотки) в начало / в конец          |
| `PgUp/PgDn` | (на полосе перемотки) на 10 секунд вперёд / назад |

Стрелки `←` и `→` пока свободны — они понадобятся для покадрового перехода.

## Тестовые видео

Для автотестов нужны короткие видео в `tests/fixtures/` (`sample.webm`, `sample.mp4`, `broken.mp4`).
Они лежат в репозитории; чтобы создать заново (нужен установленный Google Chrome):

```bash
node scripts/make-fixtures.mjs
```

Скрипт рисует 6-секундную анимацию (поле, мяч, таймкод) и записывает её через MediaRecorder в Chrome.
Если Chrome не умеет писать MP4, `sample.mp4` не создаётся, а тесты для него пропускаются.

Тесты на собранной программе: `FLOW_EXE=dist/win-unpacked/FlowAnalyzer.exe npx playwright test`.

## Важно про запуск из VS Code

Терминалы и инструменты внутри VS Code могут выставлять переменную окружения
`ELECTRON_RUN_AS_NODE=1`. С ней Electron запускается как обычный Node.js и окно не появляется.
Перед `npm run dev` или запуском приложения эту переменную нужно убрать:

```bash
# Git Bash
env -u ELECTRON_RUN_AS_NODE npm run dev
# PowerShell
Remove-Item Env:ELECTRON_RUN_AS_NODE; npm run dev
```

## Безопасность

- `contextIsolation` включён, `nodeIntegration` выключен, `sandbox` включён.
- Интерфейс получает только функции из `window.api` (описаны в `src/shared/ipc-contract.ts`).
- Видеофайлы отдаются через собственный протокол `flow-media://`: доступны только файлы, которые пользователь сам выбрал
  (диалог или перетаскивание). Произвольные пути интерфейс запросить не может.
- Навигация и новые окна блокируются, разрешения (камера, микрофон и т. д.) отклоняются.
- Строгая Content-Security-Policy в `src/renderer/index.html`.

## Структура

```
src/main        основной процесс (окно, безопасность, IPC-обработчики)
src/main/media  выдача видеофайлов: реестр, протокол flow-media (Range), проверка путей
src/preload     безопасный мост window.api
src/shared      контракт IPC (каналы и типы)
src/renderer    интерфейс (React): app, features/player, store (zustand), ui, i18n, styles
tests/e2e       тесты Playwright; tests/fixtures — тестовые видео
scripts         make-fixtures.mjs — генератор тестовых видео
build           иконки (icon.svg — исходник)
```
