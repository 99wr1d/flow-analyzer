## Что делаем (порядок согласован с пользователем, по одному стилю — со сравнением)

1. **Кольцо «как в образце»** — для кольца на поле (`ring`) и экранного круга/эллипса (`circle`), в том числе после слежения.
   - Новый вид по умолчанию для новых колец: тонкая насыщенная обводка + мягкое свечение того же цвета (ореол ≈ 2–3× толщины,
     прозрачность ~40%), без заливки (заливка остаётся ползунком 0–40%, по умолчанию 0).
   - «Лежит на траве»: у кольца на поле перспектива уже даёт разметка; у экранного круга, созданного у ног игрока, — плоский
     эллипс: если на кадре есть разметка поля, сплющивание берётся из неё (как выглядел бы круг на траве в этой точке), иначе —
     отношение высоты к ширине ≈ 0,35. Ручное изменение формы тренером не перебивается.
   - Под игроками — как сейчас (по умолчанию включено).
2. **Подписи без плашки**: новый стиль подписи «без плашки» — жирный шрифт, цвет из палитры, тонкая тёмная тень для читаемости
   на траве, без стрелки-ножки у экранной подписи. Флаг `background` уже есть — используем его; добавляем тень. Кнопка в панели
   стиля «Плашка вкл/выкл» видна сразу.
3. **«Мишень»** — новый вид кольца (переключатель «Кольцо / Мишень» в панели стиля для `ring` и `circle`): 3 концентрических
   кольца (радиусы 1, 0,66, 0,33 от внешнего) + радиальная заливка от ≈35% в центре к 0 у края; тонкие линии со свечением.
   Опция **«Пульс»**: волна от центра наружу, период ≈1,5 с, на экране и в экспорте одинаково (по времени видео, не по часам).
4. **Световой столб** — новый вид прожектора (`spot` и `pspot`, переключатель «Овал / Столб»): вертикальная полоса от верхнего
   края кадра до ног игрока, ширина ≈ ширине игрока (от размера рисунка), градиент: ярче к низу и к оси, мягкие края, свечение.
   Затемнение вокруг — как у прожектора сейчас (настройка остаётся). Работает со слежением (столб едет за игроком).
5. **Пунктир точками** — третий вид линии: «сплошная / штрих / **точки**» (круглые точки, шаг ≈ 2,5 толщины) для стрелок,
   линий, кривых, пера, цепочки — на экране и на поле.
6. **Свечение и проявление линий** — для стрелки, линии, кривой (экран и поле):
   - опция **«Свечение»**: ядро светлее цвета + ореол;
   - опция **«Проявление»**: линия прорисовывается от начала к концу за N секунд от начала отрезка рисунка (по умолчанию 0,8 с,
     настраивается 0,2–3 с); после — стоит целиком. Наконечник стрелки появляется в конце.

## Новые цвета палитры
Добавить к нынешним: **лайм** (≈ `#c6ff3d`), **ярко-синий** (≈ `#2e8bff`), **оранжево-красный** (≈ `#ff5a1f`) — подобрать
так, чтобы читались на траве; старые цвета остаются.

## Цели / не-цели / анти-цели
Цели: каждый стиль выглядит рядом с кадром образца «похоже по духу» (решает пользователь по сравнительному снимку);
одинаково на экране и в экспортированном видео; старые проекты выглядят как раньше; рисовать так же быстро, как сейчас
(новые настройки — в панели стиля, не в глубоких меню).
Не-цели: «Связка игроков» (следующий этап); автоматическое следование линии за мячом (ИИ); учёт движения камеры для рисунков
на поле (ИИ-шаг 2); копирование графики из роликов.
Анти-цели: рисунок закрывает игрока; эффекты делают экспорт заметно медленнее (ориентир: не более +30% ко времени экспорта
с рисунками); старые проекты меняют вид; новые поля ломают открытие проектов (zod, совместимость).

## Ограничения
- Экран и экспорт рисуют одними и теми же SVG-элементами (`ShapeView`/`PitchShapeView` → `renderOverlays` растеризует SVG
  через `<img>`/canvas); свечение — SVG-фильтры (размытие), они растеризуются и в экспорте — проверить на пикселях.
- Анимированные эффекты (пульс, проявление) зависят только от времени видео — экспорт уже рисует оверлеи по кадрам для
  анимации; убедиться, что эти рисунки попадают в покадровый путь.
- Новые поля стиля — необязательные в схеме (`src/shared/annotations.ts`), старые проекты читаются без изменений.
- Решение по виду каждого стиля — за пользователем: после каждого стиля — снимок рядом с кадром образца; правки вида до
  следующего стиля.

## Уточнения после проверки строителем (решения автора дизайна; пользователь может поправить)

1. **Столб** — всегда вертикальная полоса **по экрану** (от верхнего края кадра до ног), и у `spot`, и у `pspot` — один общий
   рисовальщик. Если ноги у верхнего края — столб просто короткий. Другие рисунки не обходит.
2. **Сплющивание экранного кольца** вычисляется **один раз** — при создании круга (или при старте слежения) — по разметке поля,
   если на этом кадре она есть (разметка того же кадра/плана), иначе 0,35; сохраняется самой геометрией эллипса (p1/p2), нового
   поля не нужно. При слежении форма масштабируется целиком (как сейчас), соотношение не пересчитывается. Любая ручная правка
   формы — просто новая геометрия.
3. **Умолчания.** Старые рисунки без новых полей рисуются как раньше. Новые: кольцо/круг — **свечение вкл.**; подпись — **без
   плашки, с тенью** (как в образцах); стрелки/линии — свечение и проявление **выкл.**, вид линии «сплошная». Выбор в панели
   стиля запоминается для следующих рисунков, как другие настройки стиля. Правка старого рисунка в панели меняет только то,
   что тренер переключил.
4. **Проявление** — доля длины пути = (время от начала отрезка) / N, по времени видео (перемотка и обратный ход дают ту же
   картинку для того же кадра); если отрезок короче N — N ужимается до 80% отрезка; для пера/цепочки/кривой — по длине пути;
   наконечник появляется, когда линия дошла до конца. Для рисунков с ключами/слежением — доля длины текущей геометрии.
5. **Сочетания обязательны**: точки + свечение + проявление вместе (проявление — обрезкой пути по длине/маской, а не через
   штриховку, чтобы не конфликтовать с точками).
6. **Экспорт**: всё анимированное (пульс, проявление) обязано попадать в покадровый путь экспорта — расширить, если нужно.
   Если SVG-размытие в экспорте выходит за бюджет +30%, разрешено рисовать ореол «стопкой» полупрозрачных линий/колец вместо
   фильтра — при условии, что экран и экспорт используют один и тот же способ.
7. **Процесс**: один план; общая часть схемы и палитры — первым шагом; дальше по одному стилю в согласованном порядке. После
   каждого стиля — сравнительный снимок пользователю (не ждать ответа, продолжать; правки вида — отдельными шагами по отзыву).
8. **Сравнительные снимки** делает исполнитель (Playwright по синтетическим фикстурам и/или видео пользователя локально +
   ffmpeg кадр образца рядом), складывает во временную папку и в `C:\Users\user\Pictures\FlowAnalyzer-стили\`; никакого
   инструментария в репозиторий.

Точные значения толщины ореола, прозрачностей, градиентов (подбирать по сравнительным снимкам), структура компонентов,
где именно в панели стиля переключатели, имена полей схемы.
