# «Связка игроков» — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** инструмент «Связка»: точки у ног 2–8 игроков, линия или область, кольца у ног; «Следить за игроками» ведёт все точки одной задачей.

**Architecture:** новый рисунок (экранный и «на поле») рисуется общими компонентами 0.18 (линии, заливка, кольца у ног); слежение — расширение существующей задачи до N целей: один проход детектора на кадр, N `SingleTracker`, общий запрет «две точки на одной рамке»; результат — ключи `points` всей связки (`auto`), одной записью истории.

**Tech Stack:** Electron, React, TypeScript, zod, vitest, Playwright, onnxruntime-web (уже есть).

**Spec:** `docs/superpowers/specs/2026-10-23-player-link-design.md` (читать целиком, включая «Уточнения»).

## Global Constraints
- Анти-цель: точка никогда молча не переходит на другого игрока; две точки не ведут одну рамку (это сомнение → вопрос «Точка N: кто из них ваш?»).
- Потеря любой точки → стоп всей связки на последнем уверенном кадре, сообщение с номером точки и причиной (тексты причин — как у слежения: «смена плана», «вышел из кадра», «закрыт другими игроками»).
- Старые проекты читаются и выглядят как раньше; новые поля/тип — без ломки старых версий там, где это дёшево (как `dots` в 0.18).
- Экран = экспорт; «под игроками» по умолчанию для заливки и линий связки; кольца у ног — стиль 0.18.
- Ключей ≤ `MAX_KEYFRAMES` (3000) на рисунок.
- Скорость: слежение 5 точек ≤ ×1,5 времени слежения 1 точки на тех же 10 с.
- Видео пользователя — только локально; тесты — синтетика и `FLOW_DETECTOR_STUB`.
- Electron — `env -u ELECTRON_RUN_AS_NODE`; Smart App Control не обходить; без `prettier --write` по чужим файлам.
- Тексты — по-русски в `ru.ts`; клавиша по умолчанию `L` (если занята — свободная), переназначаемая.
- Версия по завершении: **0.19.0** (в main — после согласия пользователя).

## Review Focus
- Две точки на игроках одной команды пересекаются — не меняются местами.
- Точка поставлена между двумя игроками — вопрос по этой точке, а не молчаливый выбор.
- Связка из 8 точек на 10 с — ключей ≤ 3000, время в бюджете.
- Ctrl+Z после слежения связки «на поле» возвращает рисунок на поле с метрами.
- Экспорт клипа, начинающегося посреди отрезка связки, — точки там же, где на экране.
