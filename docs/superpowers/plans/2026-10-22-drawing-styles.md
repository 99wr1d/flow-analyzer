# Новые стили рисунков — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** кольцо со свечением «на траве», подписи без плашки, «мишень» с пульсом, световой столб, пунктир точками, светящиеся линии с проявлением — одинаково на экране и в экспорте.

**Architecture:** новые необязательные поля стиля в `src/shared/annotations.ts` (старые проекты рисуются как раньше), умолчания для новых рисунков в одном месте; рисование — в общих SVG-компонентах `ShapeView`/`PitchShapeView`, которые использует и экспорт (`renderOverlays.tsx` растеризует SVG). Время-зависимые эффекты (пульс, проявление) — чистые функции времени видео, экспорт рисует их покадрово.

**Tech Stack:** Electron, React, TypeScript, SVG, zod, vitest, Playwright, ffmpeg-static.

**Spec:** `docs/superpowers/specs/2026-10-22-drawing-styles-design.md` (читать целиком, включая «Уточнения»).

## Global Constraints

- Старые проекты читаются и выглядят как раньше: все новые поля необязательные; отсутствие поля = старый вид. Тесты совместимости — `src/main/project/compat.test.ts`, фикстуры `tests/fixtures/projects`.
- Умолчания для НОВЫХ рисунков: кольцо/круг — свечение вкл., вид «кольцо», пульс выкл.; подпись — без плашки, с тенью; стрелки/линии — свечение выкл., проявление выкл., вид линии «сплошная»; прожектор — вид «овал». Выбор в панели стиля запоминается для следующих рисунков (как цвет/толщина сейчас).
- Экран и экспорт — один и тот же способ рисования; каждый стиль проверяется e2e-сравнением пикселей экрана и кадра экспорта (как существующие проверки экспорта рисунков, допуск ±3 px по положению).
- Время-зависимое (пульс, проявление) — только от времени видео; экспорт рисует такие рисунки покадрово.
- Бюджет экспорта: не более +30% ко времени экспорта с рисунками (замер на `npm run bench:export` или фикстуре); при превышении ореол — «стопкой» полупрозрачных линий вместо SVG-фильтра, одинаково на экране и в экспорте.
- Новые цвета палитры: лайм `#c6ff3d`, ярко-синий `#2e8bff`, оранжево-красный `#ff5a1f` (подстраиваемо по сравнительным снимкам).
- Тексты интерфейса — по-русски (`src/renderer/src/i18n/ru.ts`); переключатели — в панели стиля (`StyleBar.tsx`), видны сразу, без глубоких меню.
- Образцы пользователя (`C:\Users\user\Videos\flow-samples\PATTERN OF PLAY*.mp4`, `STRIKER MOVEMENT*.mp4`) и видео матчей — только локально; ни кадров, ни графики из них в репозитории.
- После каждого стиля — сравнительный снимок «наш рисунок | кадр образца» в `C:\Users\user\Pictures\FlowAnalyzer-стили\NN-<стиль>.png` (Playwright + ffmpeg во временной папке; инструментов в репозиторий не добавлять).
- Electron в shell — через `env -u ELECTRON_RUN_AS_NODE`; Smart App Control не обходить; не запускать `prettier --write` по чужим файлам (CRLF).
- Версия по завершении: **0.18.0**.

## Review Focus

- Старый проект с кольцами, подписями с плашкой, штриховыми линиями открывается и экспортируется пиксель-в-пиксель как в 0.17.0 (тест на фикстуре 0.17.0).
- Отслеженное кольцо (ключи `auto`) со свечением/«мишенью»/столбом — эффект едет вместе с игроком и в экспорте совпадает с экраном.
- Проявление при перемотке в середину отрезка и в экспорте с началом клипа посреди отрезка рисунка — та же доля линии, что на экране на том же кадре.
- «Под игроками» + свечение/мишень: ноги поверх и ядра, и ореола (ореол тоже под игроками).
- Пунктир точками на очень короткой линии и на пере с сотнями точек — без пропадания и без зависания.
